## 👨‍💻 Author
*MOHAMMED AMANKHAN*

---


📌 Project Overview

This project proposes an efficient Load Balancing Algorithm for cloud computing environments to optimize resource allocation, reduce execution time, and improve overall system performance.

The system focuses on Infrastructure as a Service (IaaS) cloud environments where virtual machines are dynamically allocated and managed to ensure balanced workload distribution across cloud resources.

---

🎯 Objectives

- Optimize resource utilization in cloud data centers.
- Improve load balancing among virtual machines.
- Reduce execution time and makespan.
- Prevent server overload and underload conditions.
- Enhance Quality of Service (QoS).
- Improve task scheduling efficiency.

---

🏗️ System Architecture

The proposed architecture consists of:

- Cloud Users
- Cloud Broker
- Virtual Machines (VMs)
- Hypervisors
- Physical Hosts
- Load Balancer
- Task Scheduler

The system dynamically allocates incoming tasks to available virtual machines while monitoring workload distribution.

🔄 Workflow

1. User submits task request.
2. Cloud broker receives the request.
3. Task scheduler analyzes task requirements.
4. Load balancer selects suitable virtual machine.
5. Task is allocated to available VM.
6. Resources are monitored continuously.
7. Makespan and execution time are calculated.
8. Results are displayed to users.
